# LihatDulu app

Vite and vanilla JavaScript frontend with Three.js inspection. See ../README.md for setup and Vercel configuration, ../DESIGN.md for visual rules, ../FLOW.md for routes, and ../QA.md for verification.

From this directory:

```sh
npm ci
npm run dev
npm run test:unit
npm run test:redesign
npm run build
npm run test:production
```

The original four GLBs remain unchanged. Sora video and evidence selection are prepared examples; no capture permissions or backend services are used.
