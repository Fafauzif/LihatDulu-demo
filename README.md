# LihatDulu application

Vite/JavaScript/Three.js application for LihatDulu V8. Read the project-root README for Vercel deployment and the active verification commands.

- `src/main.js`: navigation, shell, shared cards and controller.
- `src/discovery*.js`: applied filters, validation, taxonomy and prepared references.
- `src/product-views.js` / `product-media.js`: product, store and source-specific evidence.
- `src/buyer-records.js` / `buyer-views.js`: local offer drafts, immutable summaries and shopping review.
- `src/market-state.js`: cart, seller edits, collections, stable seller fee groups.
- `src/inspection.js` / `engine.js`: retained models, motions and room geometry.
- `src/video-capture.js` / `video-state.js`: prepared Sora seller journey.

`public/` contains retained models/media and local fonts; `dist/` is rebuilt output. No API keys, media permissions or backend are used.
