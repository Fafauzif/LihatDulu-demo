# Supporting film excerpt scope

This folder contains selected historical documentation and rendering source from the user-supplied editable film project. It is not a complete runnable film project and not the application baseline.

Use it only for provenance or targeted cabinet-rendering context. Its README names files and audio that intentionally are not included here. The complete source ZIP remains a separate supplied input, not a required dependency for this redesign.
