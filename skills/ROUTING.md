## Apply intelligently

- Taste's default core scope focuses on landing pages/redesigns and excludes multistep product UI. Use the redesign workflow and applicable principles rather than forcing its landing-page composition rules onto shopping tasks.
- Preserve useful regular product grids, filter sheets, factual status labels and consistent commerce components.
- Do not migrate to React, Tailwind or a new animation stack solely because a skill defaults to them.
- The original SVG logo is explicitly authorized. Ordinary interface icons can use a consistent licensed family.
- Ignore instructions to fabricate realistic-looking names, numbers, dates or reputation. Example profiles must be identified and external claims supported.
- Do not add noise, blur, glass effects, hover physics or cinematic motion at the cost of mobile usability/performance.
- Use one actual LihatDulu design-token system. The Etsy screenshots are the primary commerce references, not a reason to import another brand's colours.
- Guideline audits should produce actionable internal findings. Do not place audit commentary inside the website.
- Playwright CLI is a tool, not proof that tests passed. Use available browser automation with the same observation and evidence discipline. Respect the environment's authorized browser controls.

## Artifact skills

Use the execution environment's native presentation and PDF skills where available. SOURCE_LINKS.md also points to public PPTX/PDF guidance. Those third-party proprietary skill texts are not copied into this pack. The requirements in brief/BRAND.md and quality/ are self-contained.

Do not install unrelated plugins, request new accounts or create API dependencies for the prepared flows.
