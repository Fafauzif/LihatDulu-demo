# Prepared capture and visual search

## Sora capture

Sora is the only product with recording/capture.

From the populated seller workspace, open an immersive mobile capture mode. Use the whole usable browser viewport, with a neutral grey environment and the same Sora cabinet large on screen. Minimal controls overlay the scene without covering crucial furniture details.

Provide:
- Reachable close/exit.
- Current area label and one brief instruction.
- Progress indicating example-frame coverage.
- Shutter selection.
- Back and Next.
- A compact selected-frame/coverage treatment.
- A direct review path that does not require repetitive completion.

Use the supplied front, side, rear, interior, drawer and condition example areas. Advancing changes both the viewpoint and the corresponding instruction/frame. Pressing the shutter selects that area's prepared photograph. Retaking replaces that selection without increasing the count. Do not use arbitrary timers as model-processing progress.

On capable devices, the actual model and matching camera framing support the experience. Under constrained or failed graphics conditions, the corresponding prepared images keep every capture step usable. Preserve the same labels, controls and selections.

Keep Sora's articulation and interior imagery aligned. The entire open silhouette must remain in frame at short and narrow mobile viewports.

Review the photos, dimensions and condition details, then allow preview of the actual Sora buyer page. Do not claim a reconstructed asset, a published listing or real captured photographs.

Reset prepared capture only, with undo where appropriate. Never erase unrelated favourites, cart, historical photos or other product state.

## Predetermined photo-search object

The judge does not use a personal camera or upload an image.

Open Cari dari foto into an understandable prepared photo-search interface. Display a predetermined wooden-chair photograph immediately, with a brief contextual Foto contoh label and an action to find matching examples.

Create or select this example from the Arca asset production so appearance and results remain credible. Prefer an alternate setting or viewpoint of the same design family. Do not use an Etsy screenshot as a pretend camera image.

Show prepared similar results with understandable reasons, such as category, silhouette, timber tone or material. The fixture mapping and ranking should be documented internally. Do not claim live image recognition.

Arca may be the only available close chair match in this four-item catalogue. Nara can appear separately as a clearly labelled coming-soon related item, without cart eligibility. Do not manufacture several available chair matches or rank Sora/Batu/Rimba as close chair matches merely because they share a wood tone. Related items and similar items must remain intelligibly distinguished.

Optional additional prepared examples can be added only if they improve the demonstration without expanding its scope materially.

## Size suitability

After the similarity result, offer maximum width, depth and height fields or a prepared space-size preset. Apply them against each listing's canonical dimensions.

Show which candidates satisfy the size limits and how changing limits changes the result. Provide an intelligible empty state and reset.

Derive one prepared size preset from Arca's finalized dimensions so it retains Arca, and another narrower preset so it excludes Arca. Display the actual size limits and matching reason. This provides a causal result/empty-state demonstration without inventing extra inventory.

A chair photograph does not measure a room. A candidate within axis-aligned size limits is not a verified real-world placement, transport-access or opening-clearance guarantee. Actual room illustration uses confirmed example dimensions and the appropriate geometry separately.

## Feedback

Keep result changes immediate when using local fixtures. Do not add fake analysis progress or artificial processing delays. Skeletons are appropriate only for real loading.

The prepared photo, selected criteria and resulting products should form a visibly causal sequence. A camera icon opening an unrelated ordinary catalogue is insufficient.

## Public boundaries

Avoid real media APIs, file inputs, permission queries and transmission. Use supplied or authored prepared assets. Ordinary labels such as Foto contoh and Contoh: Lemari Sora can convey the scope without large technical banners.
